# v0.2 技术路线

更新：2026-09-08。本文按五类汇总已确认的 v0.2 产品方向与待实现事项，新增“用户自选主题色”。下列事项均为待做，不代表当前版本已经提供这些能力；v0.1 继续采用现有分类主管模式。

## 一、文献会话与跨文献总结

### 每篇文献一个 chat

DSH 从“每个分类对应一个主管会话”调整为“每篇文献对应一个持久 chat”。单篇 chat 负责该文献的精读、问答与讨论；分类保留为组织和筛选文献的方式。Codex 继续承担整个文献库的总管理员职责。

同一实例内以文献的稳定 `paperId` 绑定 `sessionId`，不以标题或分类名识别会话。重复入库经去重后应复用已有文献 chat；改标题、移动分类或重启实例不应丢失会话关系与历史。文献与资产仍以现有 SQLite 文献库为事实源。

### 多选 chat，由 Codex 跨文献总结

用户选择多个文献 chat，并指定总结问题；Codex 读取所选会话及其对应文献上下文，完成跨文献总结，例如共同发现、方法差异、结论冲突和仍待解决的问题。选择可以跨分类，分类不再限制总结范围。

总结必须保留文献和会话来源；涉及论文事实时应能回查原文证据，不能把 chat 中的模型推测或用户讨论直接当作论文结论。读取不完整、证据缺失或上下文被截断时，应明确说明总结覆盖范围。只读取用户选中的会话；需要扩大范围时由用户调整选择。

### 会话改造与验收

| 阶段 | 待实现内容 | 验收标准 |
| --- | --- | --- |
| 单篇会话绑定 | 将分类主管绑定改为文献与会话绑定，调整交接和工具作用域 | 一篇文献对应一个主 chat；重复导入、重启和移动分类后可续接；单篇会话不能误改其他文献资产 |
| 会话选择与读取 | 提供多选入口，向 Codex 返回所选文献身份、会话历史和证据引用 | 可跨分类选择；返回内容与所选 chat 一致；长历史的分页或截断状态明确可见 |
| 跨文献总结 | Codex 根据用户问题汇总所选会话，并保留来源 | 能区分各论文观点与讨论推测；不混入未选会话；结论可追溯到对应文献和证据 |
| 旧数据迁移 | 设计 v0.1 分类会话向单篇会话的过渡方式 | 保留原文献库、资产和历史；不能将旧分类会话中的混合讨论错误归属到某篇论文 |

旧分类会话如何保留入口、如何衔接已有单篇 Review，以及多选入口的具体交互，留到 v0.2 实现设计时确定。本次只记录路线，不改动 v0.1 会话合同或运行行为。

## 二、Figure 关联阅读与讨论

2026-09-07 已记录的需求：在 Reader 中选择某个 Figure，自动关联这张图的原文上下文，带入本篇文献的 DSH chat 持续讨论。

- [ ] 选图后关联图注、正文引用，以及方法、结果、讨论中的相关段落，处理子图和跨页引用。
- [ ] 将所选图片与带来源的上下文交给本篇 chat，支持连续追问及跳回原文；切换 Figure 时明确更新上下文。
- [ ] 用文献 ID、资产 ID 和源 PDF SHA 绑定图与上下文，避免混入其他图或文献。
- [ ] 区分图中可见信息、作者原文结论和模型推断；未提供图像时说明仅依据图注与正文，关联不足时保留不确定性。

验收须覆盖同篇多图、子图、跨页及缺少明确正文引用的样本，并在真实 DSH chat 中验证上下文和来源定位。

## 三、Excel 展示与研究字段自定义

Excel 的固定字段长期管理、已有精读成果接入、图表索引和笔记安全同步属于 [v0.1 重构范围](excel-v0.1-redesign.md)，不推迟到 v0.2。这里新增的是用户自定义字段与展示方案。

- [ ] 选择现有列的显隐、顺序、显示名、列宽和换行方式，保存与恢复展示方案。
- [ ] 新增自定义研究字段，例如实验模型、样本量；区分人工填写与 AI 提取，提取结果保留来源和证据位置。
- [ ] 支持全库默认方案和分类方案。
- [ ] SQLite 继续作为事实源，展示字段与允许回写的字段分别定义；以稳定字段 ID 和 `paperId` 回写，改列名、重排或隐藏列不应丢失原有数据。

## 四、Reader 模板与外观自定义

- [ ] **用户自选主题色（2026-09-08 新增）**：在设置页选择主题色，保存偏好，并可恢复默认。工作台与 Reader 的具体覆盖范围、与 DSH 原生主题的衔接在实现设计时确认。
- [ ] 选择或自定义 HTML/CSS 精读模板，支持导入、预览、应用和恢复默认。
- [ ] 调整字体、内容宽度和双语布局；支持全库默认模板及分类方案。
- [ ] 保留原文、译文、图表、个人批注与证据定位关系；纯样式调整复用已有解析和译文，不重新解析或翻译论文。
- [ ] 校验模板与内容组件的接口，保留内容和模板版本；无效模板不覆盖已有阅读资产。

Excel 与 Reader 自定义能力由原生插件 A 提供共享实现，工作台 B 复用，避免维护两套字段或模板机制。

## 五、文献雷达

Agent 帮助用户梳理、确认研究方向，并发现与方向相关的优质文献。

- [ ] 根据研究目标、已有文献和种子论文建立可修改、可复用的方向配置：研究问题、关键词与同义词、纳入排除范围和研究类型。
- [ ] 多来源检索、规范化 DOI/PMID 等身份，与已入库文献及历史候选去重。
- [ ] 解释推荐的相关性、研究设计与证据、阅读价值和时效性；兼顾经典研究、新进展及阴性或相反结论，不仅按期刊或引用数排序。
- [ ] 保留发现来源、检索时间、查询词、推荐依据和全文获取状态；仅有摘要时明确属于初筛，可核实时标注预印本、撤稿和更正。
- [ ] 提供按需扫描与用户设定频率的增量扫描，保留“不相关”等反馈，只提示新的相关候选。此处仅记录产品待办，不创建实际定时任务。
- [ ] 候选列表与已纳入文献分开；由用户选择纳入后衔接既有 PDF 与精读流程，发现候选本身不启动下载或解析。

可发现非 OA 文献；原生插件 A 仍只自动获取 OA PDF 或接收手动上传，B 的授权获取仍由 Codex 侧承担。检索、候选和方向配置复用 A 的共享能力，Codex 总管理员统筹方向与纳入，纳入后衔接本篇文献 chat。具体检索来源、调度方式及推荐质量验收在实现前细化。
