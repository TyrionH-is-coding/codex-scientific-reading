# v0.1 发布前工程审视（2026-09-07）

本轮形成 B rc.8 / A rc.7 本地候选。范围来自已确认的设置页、模型恢复、翻译续接与必要降重；Excel 长期管理延续上一轮整合。不增加 v0.2 功能，也不将新的诊断导出、取消面板或额外配置系统纳入此次发布条件。

## 改动与理由

| 部分 | 原问题 | 当前行为 |
| --- | --- | --- |
| 设置页 | 四块卡片职责混杂，旧插件设置仍留有空字段表单 | 四组纵向设置行；环境详情折叠；同实例 OAuth 状态与入口；模型按钮复用 DSH 原生窗口；窄窗口自动换行 |
| 页面滚动 | 固定高度形成双重滚动，底部输入框遮挡说明 | 使用宿主滚动区，按其输入框高度预留底部空间 |
| 模型进程 | 一次退出使连接永久 closed | 故障与主动关闭分离，下一次请求创建一个新进程；失败请求不自动重放；过期进程事件不污染新连接 |
| 会话恢复 | 进程代次变化后缓存失效，工具结果可能不明 | 原生会话可恢复时复用；不能恢复时依据 DSH 已持久历史重建；工具结果未知时停止推断 |
| 翻译回传 | 重复提交英文、初步高亮增加格式出错面 | v4 输入仅含块 ID 与译文，另带批次及来源 SHA；服务器绑定英文，最终复核仍负责高亮；兼容 v3 |
| 缺译补交 | 部分正确结果无法积累，多轮重复同批 | 合法部分写入草稿，重启后只读取剩余块；已接收译文不能被补交覆盖；第三次仍未完成后暂停 |
| 故障线索 | 缺少可追踪的生命周期记录 | 仅记录时间、进程代次、固定事件与原因码，64 KB 轮转；不写原始 RPC、标准错误、登录信息或论文正文 |

## 必要降重与保留项

删除旧空设置表单的字段遍历、无效保存/重置和订阅逻辑；共享 CLI 与服务端的翻译输入结构校验。未为单处使用引入新框架。源码 SHA、资产路径、幂等回执、工作簿冲突保护与未知工具结果拦截继续保留，不能为了缩短代码将其删掉。

不合并 B 的交接账本与 OAuth 原生会话恢复：前者记录文献任务和权限边界，后者处理模型进程传输，失败后的证据不同。`engine/build` 属于构建缓存；正式 wheel 仍由独立构建目录生成并与源文件逐项核验。

## 验收与证据边界

本机 Windows 完整文献引擎回归 514 passed / 3 skipped；插件离线合同、真实 CLI、wheel 与文献资产检查通过。B 单元回归 56 passed / 1 skipped，OAuth 41 passed；另运行官方 Codex CLI 的隔离未登录检查。跳过项目未视为通过。

新增回归覆盖来源/批次 SHA、未知或重复块、顺序错误、草稿重启续传、拒绝覆盖已接收译文、暂停后的用户续接、并发启动、进程退出/协议错误/超时恢复、登录过程中断及日志轮转。输入结构错误在 CLI 拒绝；分类提示另限制格式纠正次数。引擎硬限制针对已经提交给任务执行器但仍未完成的批次，不等于承诺所有模型失败都会自动恢复。

Codex 内置浏览器已检查真实 DSH 中的新设置行、原生模型窗口及关闭返回、环境重检、折叠信息和 600 px 窄窗口。路径复制按钮有成功回执，但当前内置浏览器的剪贴板读取未返回内容，因此不将跨应用粘贴算作已验收。页面采用临时独立 Profile 和虚构论文，未改用户正在运行的 DSH 或论文资产。

发布附件必须由此轮提交重新编号生成，逐文件读回 SHA；正式归档安装、启停、恢复、Excel 和卸载保留检查以配套 `platform-win32-x64.json` 为准。安装包内 `BUILD-MANIFEST.json` 和外部 `RELEASE-MANIFEST.json` 分别记录 B/A 的实际提交及附件哈希。macOS 归档在 Windows 生成并读回校验不等于 Mac 实装通过。

仍需在新候选上完成 Mac 实装，重点核对本人 OAuth、模型中断后的继续、真实长文翻译及原生 Excel/Numbers 保存关闭后回写。Windows 未登录 CLI 和模拟模型回归不替代这些测试；Spark / GPT-6 Astra 的实际账号模型测试仍独立记录。合并到本机 main 也不等于 GitHub CI、tag 与 Release 已通过。

候选验收不替用户确认已读、译文或科学结论。
