# Excel v0.1 整合验收

日期：2026-09-07。用户确认固定字段 Demo 后，将其管理逻辑接入 A 生产引擎和 B Codex 接口。开发版本为 B rc.7 / A rc.6；旧公开 rc.6 附件不变。本页不代表已经创建新版 GitHub Release。

## 实现范围

- SQLite 格式 5 保存六个个人字段、真实维护时间和导出基线。人工阅读进度与后台处理进度独立；个人字段进入检索。
- 工作簿以文献、阅读成果、图表索引组织内容。阅读成果来自经过来源校验的现有 Reader 导读及已确认记录，不在导出时调用模型。PDF 更新后历史确认保留并标明证据状态。
- 正式 `personal_update` 使用字段白名单和旧值校验；`excel_sync` 比较导出基线、Excel 和库内值。支持整表排序、清空、并发修改与旧表迁移；冲突保留原表，原始工作簿按哈希备份。
- Codex 接口可按个人关键词、阅读进度、最近维护时间检索；实时状态返回实际导出回执。首次入口解释独立 OAuth / 模型配置及 MinerU 保存与验证的区别。
- 安装器先快照再允许格式 4 → 5 升级。新版可能写库后若启动失败，恢复继续新版；拒绝格式 5 → 4 的旧程序回退。

## 尚需实机验收

macOS Excel / Numbers 和 Linux LibreOffice 的原生编辑、排序、链接与回写尚未在本轮操作。Windows Excel 结果不能代替其他平台。用户提供的 Mac 报告使用 B rc.5 / A rc.4，证明经现场处理后真实论文链路可完成，但不是本轮新表的验证。

本人 OAuth、真实 MinerU 请求、译文和科学结论质量不计入本轮工程测试。provider 意外退出恢复、精简翻译回传协议、等待任务自动继续仍按 [macOS 报告跟进](macos-first-run-followup.md) 单列；本轮没有把这些待办写成已修复。
