# v0.2 新增合同

请求外层仍为 `{action,payload}`；下面表格中的子动作放在 `payload.action`。先读实际 ID、revision 与 SHA，不编造游标和来源。

## 模型分工与在线阅读

设置页可分别选择 11 个步骤的模型及思考深度，默认翻译 Luna、分析 Sol，思考深度均为 medium。以连接返回的能力为准，不支持的档位不能发送；“模型默认”表示不强制指定深度。

总管理员自己的对话模型仍由 Codex 控制。需要生成工作台中的翻译、研究方向、候选评估、分类或研究字段时，调用 `model_run`，不要用自己的模型输出替代用户选择。`payload={step,input}`，input 包含已读取的原文、SHA/定位及要求的 JSON 合同。返回文字必须验证后再调用对应的提交接口；生成不会直接入库或覆盖人工字段，也不会自动确认雷达配置。

step 可为 `radar_direction`、`radar_assessment`、`abstract_translation`、`full_translation`、`full_review`、`classification`、`research_fields`、`paper_chat`、`figure_chat`、`multi_paper_summary`、`reader_chat`。图像讨论继续使用 `figure_discuss`；`model_run` 只接收文字，不能声称看过图片。

原生文献 chat 用 `sr_model_step` 切换分析步骤；摘要与全文任务会根据当前 gate 自动分配翻译或导读模型。在线 Reader 的悬浮球支持选区解释和追问，快捷键 Alt+Shift+E。导出链接为 `/sr/reader/<paper_id>?download=1`；HTML 含正文、译文和内嵌图片，手机浏览器可离线阅读，不包含悬浮对话记录或模型连接信息。在线表示连接本机工作台，不代表已经部署公网服务。

## 多篇历史与 Figure

`chats_select` 需要 `question` 和 `selection:[{paper_id}]`，最多 20 篇。`chats_read` 不传 selection 时使用已保存范围；每页默认 40 条原生消息、24000 字符，可传 `maxMessages`（1–100）和 `maxChars`（100–100000）。

每篇 `history` 返回 `beforeSeq`、`nextBeforeSeq`、`textOffset`、`nextTextOffset`、`pageSha256`。当前页尚有文字时，在该篇 selection 中带回原 `beforeSeq`、`pageSha256` 和 `textOffset:nextTextOffset`；读完当前页后用 `beforeSeq:nextBeforeSeq` 取更早一页。不同页不要沿用旧 SHA。保留 `truncated`、`eventSeqRange` 与 `included`；图片在历史中仅为引用，不代表已读图像。

`chats_legacy_read` 使用 `session_id`，续页字段同上。只能读取 `chats_legacy` 返回的登记入口；每页 40 条/32000 字符。其 `evidence_boundary` 说明旧分类混合讨论或旧 Review 的身份。

`figure_discuss` 使用当前 `paper_id`、`asset_id`、`source_pdf_sha256`，可带 `question`、`text_only`、当前上下文的 `expected_revision`。返回图像发送状态、真实源 SHA、正文定位与 session_id；等待原生会话实际处理，不由请求发出推断模型已看到图片。未经确认的 PDF 替换或陈旧版本会被拒绝。

## library_views

| 子动作 | 字段 | 用途 |
| --- | --- | --- |
| theme_get / theme_save | 保存时 `accent:"#RRGGBB"`，恢复为 null | 用户自选主题色 |
| schemes | `kind:"xlsx"` 或 `"reader"` | 字段目录、方案和范围默认 |
| field_save | `label,description?,field_id?` | 定义/改名自定义研究字段；ID 不变 |
| values | `paper_id` | 当前值、revision 和摘要来源 SHA |
| value_set | `paper_id,field_id,value,expected_revision` | 人工填写 |
| ai_set | 上述字段及 `evidence` | AI 来源填写，不能覆盖人工值 |
| scheme_save | `kind,name,config,scope_folder_id?,scheme_id?,expected_revision?` | 保存方案；新建 revision 为 0，编辑使用读回版本 |
| scheme_default | `kind,scope_folder_id?,scheme_id` | 应用方案；null 恢复继承或内置 |
| reader_effective | `paper_id` | 有效方案 |
| reader_render | `paper_id,config?` | 不落盘的校验预览，返回原始/显示 SHA |

摘要证据为 `[{kind:"abstract",language:"en",quote:"原文短引文",sha256:"刚读取的摘要 SHA"}]`；正文证据使用 A 已返回的 evidence locator，不自行拼定位。`source_matches_current:false` 的旧证据须重新核对。

Excel config 为 `{columns:[{field_id,label?,hidden?,width?,wrap?}]}`。字段 ID 从 schemes 返回目录选择，宽度 6–120；省略的字段附加在末尾。禁止重复字段与冲突显示名。

Reader config：`theme` 为 paper/light/dark；`font` 为 serif/sans/mono；`font_size` 14–26；`width` 640–1600；`layout` 为 original/interleaved/side_by_side/chinese；`html_template` 必须有一次 `{{content}}`；`css` 为无外部资源的样式。先 `reader_render`，读回成功和 SHA 后才保存应用用户选择的方案。

## radar

| 子动作 | 字段 | 用途 |
| --- | --- | --- |
| list | 无 | 当前方向及状态 |
| draft | `name,config,direction_id?,expected_revision?` | 新建/编辑草稿；编辑撤销确认 |
| preview | `direction_id` | 外发查询与确认说明 |
| confirm | `direction_id,expected_revision,confirmed:true` | 仅在用户已确认这版配置后调用 |
| pause | `direction_id,paused:true/false` | 暂停或恢复已确认方向 |
| scan | `direction_id,expected_revision,mode:"discovery"/"incremental"` | 有界发现或继续增量窗口 |
| candidates | `direction_id,offset?,limit?` | 来源、反馈、四维评估与候选 SHA |
| assess | `direction_id,candidate_id,metadata_sha,config_revision,expected_revision,assessment` | 保存带证据的四维 AI 评估 |
| feedback | `direction_id,candidate_id,state,reason?` | 用户相关/不相关/稍后/未评估选择，state 为 relevant/irrelevant/later/unreviewed |
| admit | `direction_id,candidate_id,metadata_sha,confirmed:true,folder_id?` | 用户明确纳入，返回正式 paper_id，不下载 PDF |
| notifications | `acknowledge?:true` | 新相关候选；实际呈现通知时才确认已读 |

最小 config：`{question:"研究问题",focus_groups:[["概念及同义词"],["另一个概念"]]}`。可选 `goal,inclusion,exclusion,research_types,seed_paper_ids,sources,recent_since,include_classics,counter_terms,crossref_query,interval_hours,page_size`。sources 使用 `europe_pmc`、`crossref`；interval_hours 默认 0（不自动扫描），page_size 为 5–100。先澄清目标、范围和种子论文，不能只替用户填一个关键词就宣称完成方向配置。

assessment 含 `verdict:relevant/uncertain/not_relevant`，及 `relevance/design/reading_value/timeliness` 四项，每项 `{reason,evidence:[{field,quote}]}`。field 可为 title/abstract_en/publication_types/publication_date/year；quote 必须逐字出现在当前候选元数据，服务端另行绑定原来源记录与 SHA。附 `limitations`，明确只读摘要或元数据。此接口不接收未经核验的全文质量断言。

初次检索按数量截断；增量在固定窗口内分页，部分失败保留进度，已配置定期扫描的未完成窗口每分钟续接。工作台关闭时不扫描。Crossref 当前游标每页变化，重用原始参数；不自行拼接或重置游标。来源数据动态变化，不能承诺穷尽全部文献。初筛保持 uncertain，只有仍有效的相关评估才进入通知；人工反馈和已入库状态优先保留。
